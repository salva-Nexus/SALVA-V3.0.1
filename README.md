# Salva v3

Salva v3 redesigns how trades and liquidity work across the platform to give merchants full pricing control.
## What's New in v3

- **One Unified Swap Experience**
  Replaces separate "Buy" and "Sell" tabs with a single, seamless trade route for any token pair.

- **Native ETH Liquidity**
  Merchants can now add or withdraw ETH directly as liquidity — no need to wrap it into a token first.
