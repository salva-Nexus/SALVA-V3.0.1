# Salva v3

Salva v3 redesigns how trades and liquidity work across the platform to give merchants full pricing control while keeping network fees virtually zero.

## What's New in v3

- **One Unified Swap Experience**
  Replaces separate "Buy" and "Sell" tabs with a single, seamless trade route for any token pair.

- **Custom Merchant Spreads**
  Merchants can set independent buy and sell prices to protect their profit margins and cover currency volatility.

- **Single-Step Price Lookups**
  Combines both buy and sell prices into a single memory slot, cutting background verification steps in half to save on user network fees.

- **Ultra-Low Network Costs**
  Built specifically for Layer 2 networks and BNB Chain so every trade executes with sub-cent transaction fees.# SALVA-V3.0.1
